# URUZ Flow Prototype v8

This version fixes branding assets using the ORIGINAL Uruz emblem extracted directly from the supplied Uruz logo.

## Asset separation

PWA / Add to Home Screen:
- `icon-192.png`
- `icon-512.png`
- `apple-touch-icon.png`

Browser favicon only:
- `favicon.svg`
- `favicon-16.png`
- `favicon-32.png`
- `favicon-48.png`
- `favicon-64.png`

Source emblem:
- `uruz-emblem-original.png`

The browser favicon is not used as the PWA icon, and the PWA icon is not used as the browser favicon.

## Deploy
Upload all files directly to the repository root. No assets folder is required.
