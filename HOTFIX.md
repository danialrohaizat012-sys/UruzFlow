# V16.1 Splash Hotfix
- Splash has an independent CSS fail-safe and JS fail-safe.
- Firebase bootstrap errors can no longer trap the user on splash.
- Firebase module is self-contained.
- Spark mode loads only companies + jobs after login.
- Service worker uses a new cache version and network-first loading for index/config.
- If an older installed PWA is still cached, deploy this build, close/reopen it once, or remove/re-add the PWA.
